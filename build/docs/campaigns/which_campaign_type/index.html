What campaign type should I use?

Estimated reading time: 4 minutes.

Use this guide to choose the right campaign quickly.

Campaign TypeBest ForRecommended For
Connector CampaignSending connection requests to new prospectsOutbound prospecting and list growth
InMail CampaignReaching prospects you are not connected toPremium users targeting specific decision-makers
Messenger CampaignMessaging existing connectionsFollow-ups and nurture sequences
Flow CampaignMulti-step outreach journeysTeams running structured, longer funnels
Auto Accept CampaignAutomatically accepting incoming requestsUsers receiving high request volumes
Schedule Post CampaignPublishing content on a schedulePersonal branding and engagement consistency

Quick decision rules​

  1. If you need new connections, start with Connector Campaign.
  2. If you already have connections, use Messenger Campaign.
  3. If you need to reach non-connections directly, use InMail Campaign.
  4. If your outreach needs several stages, use Flow Campaign.
  5. If your goal is content cadence, use Schedule Post Campaign.

Recommended first setup​

For most new users:

  1. Start with Connector Campaign.
  2. Add contacts from LinkedIn search or CSV import.
  3. Configure connection + follow-up steps.
  4. Monitor performance from campaign reports.

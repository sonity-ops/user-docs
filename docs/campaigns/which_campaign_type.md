# What campaign type should I use?

Estimated reading time: 4 minutes.

Use this guide to choose the right campaign quickly.

| Campaign Type | Best For | Recommended For |
| --- | --- | --- |
| Connector Campaign | Sending connection requests to new prospects | Outbound prospecting and list growth |
| InMail Campaign | Reaching prospects you are not connected to | Premium users targeting specific decision-makers |
| Messenger Campaign | Messaging existing connections | Follow-ups and nurture sequences |
| Flow Campaign | Multi-step outreach journeys | Teams running structured, longer funnels |
| Auto Accept Campaign | Automatically accepting incoming requests | Users receiving high request volumes |
| Schedule Post Campaign | Publishing content on a schedule | Personal branding and engagement consistency |

## Quick decision rules

1. If you need new connections, start with **Connector Campaign**.
2. If you already have connections, use **Messenger Campaign**.
3. If you need to reach non-connections directly, use **InMail Campaign**.
4. If your outreach needs several stages, use **Flow Campaign**.
5. If your goal is content cadence, use **Schedule Post Campaign**.

## Recommended first setup

For most new users:

1. Start with **Connector Campaign**.
2. Add contacts from LinkedIn search or CSV import.
3. Configure connection + follow-up steps.
4. Monitor performance from campaign reports.

# AI Errors

When using the AI to generate posts, you may encounter errors. Here are some common errors and how to resolve them.

:::note
These errors will be displayed in the bottom-right corner of the app.
:::

## Wrong API Key
If you are using an incorrect API key, you may encounter the following error:

![Wrong API Key](/images/ai_errors/invalid_key.png)

To resolve this error, make sure you are using the correct API key.


## Quota Exceeded
If you have exceeded your quota, you may encounter the following error:

```
AI generation failed because your API key quota is exceeded. 
Please check your OpenAI plan and billing details.
```

To resolve this error, make sure you have not exceeded your quota. You can check your quota usage in your account dashboard.
